# GEO Monitor AI

Telegram бот для мониторинга инфоповодов по GEO.

Функции:
- сбор новостей через RSS
- хранение в PostgreSQL
- AI-анализ новостей
- генерация маркетинговых идей
- генерация заголовков
- отчёты по GEO
- Telegram интерфейс

Стек:
- Python
- PostgreSQL
- SQLAlchemy
- Aiogram
- Gemini API
